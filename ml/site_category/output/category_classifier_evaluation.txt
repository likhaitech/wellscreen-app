Held-out real-world false-positive check
======================================================================
200 real, genuinely unseen safe domains (validation/safe_domains_heldout.txt) - NOT used in training or the stratified test split above.

False-positive rate (predicted as a HARMFUL category) at various confidence thresholds:
  threshold >= 0.50: 14/200 (7.0%)
  threshold >= 0.60: 10/200 (5.0%)
  threshold >= 0.70: 8/200 (4.0%)
  threshold >= 0.80: 3/200 (1.5%)
  threshold >= 0.85: 1/200 (0.5%)
  threshold >= 0.90: 1/200 (0.5%)  <-- LIVE_DEPLOYMENT_THRESHOLD
      false positive: odnoklassniki.ru -> drugs (0.902)
  threshold >= 0.95: 0/200 (0.0%)

DECISION: the app only acts on live ML predictions where category in ['gambling'] AND confidence >= 0.9 (see SiteCategoryMlClassifier in the Dart app and this file's module-level comment for the full reasoning). Note on statistical honesty: 0 observed false positives out of 200 samples does not mean a mathematically guaranteed 0% real-world rate - it means the true rate is very likely low, not that it is zero. Stated plainly, not overclaimed.
